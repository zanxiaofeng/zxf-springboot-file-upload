# 协议调查菜单

## 使用方式

只读取当前调用链实际出现的类型。菜单表示可调查项，不是必须填满的模板；无业务意义的小节省略。所有值按当前源码和依赖版本实证，动态值写 `{占位符}`，配置保留原生形式并在需要时说明默认值与覆盖关系。

## 目录

- Inbound：HTTP／gRPC Server、MQ Consumer、定时任务／CLI／事件。
- Outbound：HTTP、Database、缓存、MQ Producer、gRPC、对象存储、SFTP／FTP、自定义 TCP／UDP、子进程、文件系统、SMTP、进程内重要操作。

## 一、Inbound

### 1. HTTP／gRPC Server

按需记录：

- Method／Path 或 proto 全限定 method；参数来源与 Content-Type。
- 鉴权、授权、请求体上限和平台限制。
- Request／Response 字段契约、序列化和关键数据映射。
- Schema 校验机制及整体定义位置。
- 主成功路径、错误映射和实际翻译层。
- 异步受理时，结果如何通过轮询、回调或通知取得。

若采用「202 + 轮询」，分别表达受理错误与终态错误；轮询入口另建 I 卡，记录进行中占位、终态集合、结果保留和淘汰后行为。其他异步设计不得强行套用轮询语义。

### 2. MQ Consumer

- Topic／Queue、消费组、订阅和序列化。
- Message Body、业务 Headers 和 schema 来源。
- 推／拉、并发、顺序性、幂等与去重。
- 重试、毒消息、DLQ 和最终对外副作用。

### 3. 定时任务／CLI／事件监听

- cron、命令或事件源；参数与环境输入。
- 单实例锁、并发、重入和漏跑补偿。
- 主处理逻辑、失败处置和告警。

## 二、Outbound

### 1. 下游 HTTP

- 客户端库、Method／URL、Headers、Body 和响应契约。
- 关键字段来源与响应消费去向。
- 连接／读超时、重试、幂等键、熔断和降级。
- 非成功状态及连接失败的传播路径。

### 2. Database

- 表、读写操作、参数绑定、返回值和影响行数。
- MyBatis 等映射 SQL 逐字提取；原生驱动保留占位符。
- ORM／JPQL 派生 SQL 标为「派生」，注明实体、方法、方言或版本依据，不伪称运行时抓包。
- 事务承担者、回滚规则、隔离、锁、分页和读写分离。
- 约束冲突、死锁等失败的真实翻译路径。

### 3. 缓存

- Redis／Memcached 原生命令；本地缓存使用客户端 API 并标注进程内。
- Key 模式、Value 结构、序列化、TTL。
- miss 回源、更新一致性、穿透防护和失败降级。

### 4. MQ Producer

- Topic／exchange／routing key、payload、序列化和分区 key。
- 同步／异步、事务消息、确认机制和投递语义。
- Kafka 等二进制协议可使用明确标注的伪命令，不冒充协议原文。
- 本地重试、outbox、丢弃、日志和补偿去向。

### 5. gRPC

- proto 全限定 method、request／response message 和同步／异步 stub。
- 地址、deadline、metadata 和凭证来源。
- status code 的处置与向 Inbound 的传播。

### 6. 对象存储

- SDK 操作名或 REST 方法、bucket、key 模板和元数据。
- 凭证来源、SDK 内建重试和超时。
- 上传／下载失败的本地清理与降级。

### 7. SFTP／FTP

- 会话、认证、连接复用和 known_hosts 校验。
- 使用明确标注的操作序列表达 `CD`／`PUT`／`GET` 等行为。
- 覆盖策略、目录缺失处理、触发时机和失败清理。

### 8. 自定义 TCP／UDP

- 地址、帧格式、长度前缀、编码和会话交换。
- 连接／socket／应用层超时分别取证。
- 粘包、分包、重连、熔断和协议错误处置。

### 9. 子进程／CLI

- 可执行文件来源、完整参数、工作目录和环境继承。
- stdin／stdout／stderr、输出解析和退出码语义。
- 超时、强杀进程树、孤儿进程和清理责任。

### 10. 文件系统

- 路径模板、配置来源、目录权限和覆盖／追加策略。
- 临时文件、rename、copy／move／delete 操作序列。
- 跨文件系统降级、失败归档、残留和清理责任。

### 11. SMTP

- 会话、STARTTLS／明文、认证来源。
- FROM／TO／CC、主题和模板来源。
- 同步阻塞或异步发送，以及失败是否影响主链路。

### 12. 进程内重要操作

记录库与版本、输入来源、输出消费、按内容分流、资源上限和已知限制。标题标注「进程内，无外部系统」，不套用网络请求菜单，也不计入外部依赖数量。
